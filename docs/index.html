Nothing leaves your browser.

Boosts needs access to the sites you use, because a per-site injector cannot know in advance which ones you will want. Here is exactly what it does with that.

  • ✓No network calls of any kind. Not for sync, not for telemetry, not for updates. grep the repository for fetch and you will find nothing outside the tests.
  • ✓No account, no server. Everything lives in your browser's own local storage and is readable in DevTools whenever you want to look.
  • ✓No build step, no dependencies, no minification. About 3,000 lines of plain JavaScript you can read in an afternoon.
  • ✓Imports arrive switched off. A file someone else wrote is shown to you in full (which sites, and whether it runs JavaScript) before anything is stored.
